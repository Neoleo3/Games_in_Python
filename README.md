## Project
In this project, I have created a catalog of games for an employee at a company who wants play some games. Here, there are 6 games for an employee to choose from. He can play with a friend or with the computer. 
## Methodology
OOPS classes are created for each individual games in Jupyter Notebook.
Web development on the games is done using SteamLit module in Visual Studio Code.
Deployement using StreamLit online services.
